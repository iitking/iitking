## 👨‍💻 About Me

I'm an **IIT Roorkee Electrical Engineering** graduate who builds **AI systems end to end**: multi-agent platforms, RAG pipelines, voice assistants, and computer-vision robotics. I like turning complex problems into practical, tested, well-documented software.

- 🤖 Building **agentic AI**: multi-agent orchestration, tool calling, guardrails, and LLM evaluation
- 🔎 Working on **RAG**: retrieval, chunking and embedding experiments, LLM-as-judge evaluation
- 🚗 Mixing **AI + electrical engineering**: computer vision, control systems (PID/MPC), sensor fusion, embedded systems
- 🧪 I care about **engineering quality**: automated tests, Docker, CI, and clear documentation
- 🌱 Currently exploring **MLOps and AWS** to take AI systems into production
